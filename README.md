# 🌐 Portofolio Web - Firman Ramadhan Saputra

Selamat datang di repositori website **Portofolio Web Pribadi Firman Ramadhan Saputra**. Website ini dirancang secara modern, interaktif, dan penuh responsivitas untuk menampilkan profil profesional, proyek web yang telah dikerjakan, serta koleksi sertifikat keahlian.

---

## 🌟 Fitur Utama

- **🌙 Dark Mode & Light Mode**: Fitur pergantian tema terang/gelap yang responsif dan menyimpan pilihan pengguna di `localStorage`.
- **📜 Lenis Smooth Scrolling**: Efek gulir (scrolling) halaman yang sangat halus dan presisi di seluruh navigasi website.
- **✨ Animasi Dynamic & Aesthetic**: Diperkaya dengan pustaka animasi GSAP dan **AOS (Animate On Scroll)** untuk pengalaman visual yang menarik.
- **📱 Desain Responsif**: Tampilan yang optimal di berbagai ukuran layar (Desktop, Tablet, & Smartphone) menggunakan Bootstrap 5.
- **🖼️ Modal Preview Sertifikat Interaktif**: Memungkinkan pengunjung melihat detail gambar sertifikat secara langsung melalui modal pop-up.

---

## 📁 Struktur Halaman & Proyek

Website ini terdiri dari halaman utama dan beberapa halaman detail proyek serta sertifikat:

| Halaman | Deskripsi |
| :--- | :--- |
| `index.html` | Halaman utama portofolio yang memuat Jumbotron, Profil, Ringkasan Proyek, Sertifikat, dan Media Sosial. |
| `interior.html` | Landing page toko furniture minimalis modern lengkap dengan katalog produk dan fitur interaktif. |
| `pkm.html` | Detail kegiatan Pengabdian Kepada Masyarakat (PKM) Pembuatan Sistem Inventaris AMR Aquarium. |
| `labiba.html` | Platform kuis & pembelajaran interaktif berbasis web untuk anak-anak (Calistung, Mengaji, SD). |
| `sertifikat-dicoding.html` | Galeri sertifikat keahlian dari platform Dicoding Academy. |
| `sertifikat-dqlab.html` | Galeri sertifikat pembelajaran Data Science & Analytics dari DQLab. |
| `sertifikat-kuliah.html` | Koleksi sertifikat akademik dan prestasi tingkat perkuliahan. |
| `sertifikat-sekolah.html` | Koleksi sertifikat dan penghargaan masa sekolah. |

---

## 🛠️ Teknologi yang Digunakan (Tech Stack)

- **Frontend Core:** HTML5, CSS3, JavaScript (ES6)
- **Framework UI & Icon:** [Bootstrap 5.3](https://getbootstrap.com/), [Bootstrap Icons](https://icons.getbootstrap.com/)
- **Smooth Scroll:** [Lenis Scroll](https://lenis.darkroom.engineering/)
- **Animation Libraries:** [GSAP 3](https://gsap.com/), [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- **Font & Graphic Assets:** Google Fonts, SVG Waves

## 🚀 Cara Menjalankan Proyek Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username/frmnrmdn.profile.git
   ```

2. **Buka direktori proyek:**
   ```bash
   cd frmnrmdn.profile
   ```

3. **Jalankan Website:**
   - Cukup buka file `index.html` langsung di peramban (browser) pilihan Anda, atau
   - Gunakan ekstensi **Live Server** di VS Code untuk pengalaman pratinjau lokal terbaik.
